## 中文说明[cite: 1]

**OfficeGitSync** 是一款基于 Git 与系统级文件监控（Watchdog）技术的轻量级文档自动备份与版本恢复工具。专门针对 WPS / Office / 设计图纸等日常工作文档进行了防丢、防误删优化。[cite: 1]

### ✨ 核心特性 (v0.1.1)[cite: 1]

* 🚀 **无感防抖监控**：基于 Watchdog 实时监听文件保存事件，内置防抖机制（自动合并短时间内的多次保存）。[cite: 1]
* 🧹 **智能过滤垃圾文件**：自动过滤 WPS/Office 软件生成的隐藏锁文件（如 `~$*.docx`、`.tmp`、`.bak`）。[cite: 1]
* 🛠️ **纯 Python 底层驱动**：无需在电脑上预装复杂独立的 Git 客户端（内置 Dulwich 原生解析 Git 对象）。[cite: 1]
* 📜 **可视化历史版本回滚**：提供表格化时间戳版本树，支持无损追加还原（不会丢失任何历史版本）。[cite: 1]
* 🔒 **开机自启与托盘静默**：支持 Windows 开机自启（默认静默启动）、系统托盘后台运行及单实例启动保护。[cite: 1]

### 📦 安装与使用[cite: 1]

#### 1. 直接下载运行（推荐）[cite: 1]

前往 [GitHub Releases](https://www.google.com/search?q=https://github.com/fuypck/OfficeGitSync/releases) 页面直接下载编译好的 `OfficeGitSync_v0.1.1.exe` 即可使用。[cite: 1]

#### 2. 从源码编译 (Windows 环境)[cite: 1]

```bash
# 1. 克隆仓库
git clone https://github.com/fuypck/OfficeGitSync.git
cd OfficeGitSync

# 2. 创建并激活虚拟环境（可选）
python -m venv venv
venv\Scripts\activate

# 3. 安装依赖库与打包工具
pip install dulwich watchdog pystray pillow pyinstaller

# 4. 打包生成 Windows 单文件 EXE
pyinstaller --noconsole --onefile --name "OfficeGitSync_v0.1.1" git_sync.py

```

## English Description[cite: 1]

**OfficeGitSync** is a lightweight document auto-backup and version management utility powered by Python, Git (via Dulwich), and Watchdog file system monitoring. It is designed to prevent accidental file loss or overwrite issues in office environments (WPS, MS Office, design source files, etc.).[cite: 1]

### ✨ Key Features (v0.1.1)[cite: 1]

* 🚀 **Silent & Smart Monitoring**: Real-time folder monitoring with configurable debounce time to handle quick successive save events seamlessly.[cite: 1]
* 🧹 **Office Lock-File Filtering**: Automatically ignores temporary and lock files generated by WPS and Office (e.g., `~$*.docx`, `.tmp`, `.bak`).[cite: 1]
* 🛠️ **Standalone Git Engine**: Uses Dulwich pure-Python Git implementation; no standalone Git client installation required.[cite: 1]
* 📜 **Visual Version Tree & One-Click Restore**: Easily browse timestamped revision histories and perform non-destructive commit restores.[cite: 1]
* 🔒 **Auto-Start & Tray Minimization**: Supports Windows boot auto-start (launched minimized), system tray minimization, and single-instance runtime control.[cite: 1]

### 📦 Installation & Build[cite: 1]

#### 1. Download Release[cite: 1]

Download the pre-compiled executable (`OfficeGitSync_v0.1.1.exe`) directly from [GitHub Releases](https://www.google.com/search?q=https://github.com/fuypck/OfficeGitSync/releases).[cite: 1]

#### 2. Build from Source (Windows)[cite: 1]

```bash
# 1. Clone the repository
git clone https://github.com/fuypck/OfficeGitSync.git
cd OfficeGitSync

# 2. Set up virtual environment (Optional)
python -m venv venv
venv\Scripts\activate

# 3. Install dependencies
pip install dulwich watchdog pystray pillow pyinstaller

# 4. Compile to executable
pyinstaller --noconsole --onefile --name "OfficeGitSync_v0.1.1" git_sync.py

```
