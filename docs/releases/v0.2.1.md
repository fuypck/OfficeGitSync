OfficeGitSync v0.2.1 Rust 预览版。

- 远程仓库可浏览本地或已挂载的网络目录，支持 Windows UNC 和手动输入 Git URL、SSH 地址。已有仓库可直接登记，空目录需确认后才初始化为裸仓库。

### English

OfficeGitSync v0.2.1 Rust preview.

- Browse local or mounted network directories for Git remotes, or enter a Git URL, SSH address, or Windows UNC path. Existing repositories can be registered directly. Creating a bare repository in an empty directory requires confirmation.
- Fetch or explicitly push the current branch to a local bare repository. Non-fast-forward pushes are rejected.
- Import legacy Python settings through a JSON file picker on Windows and Linux or enter the path manually. Import errors explain the cause.
- Find the GitHub and Lanzou links in Settings.

Linux tests, Windows x64 cross-checks, and native Windows CI passed. The user also validated the changes on a physical Windows system. The attached Windows x64 executable is the native build of this tag.
